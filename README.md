# Drinks.com

A website to browse and buy drinks, built with Express.js.

## Project structure

- `app.js` — the main Express application
- `routes/drinks.js` — routes for browsing and purchasing drinks
- `routes/index.js` — general site routes
- `views/` — page templates
- `public/` — static assets
- `database/` / `dbconnection.js` — database connection setup

## Getting started

```bash
npm install
npm start
```

## Tech stack

- Node.js / Express
